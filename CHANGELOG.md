# Changelog

All notable user-visible changes to the SABnzbd TOS application package.

## 5.1.3-1 — 2026-11-08

### Added
- First release. SABnzbd (`linuxserver/sabnzbd:5.1.3`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8007 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/sabnzbddocker/`.
